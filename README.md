# DataStructures-Learning

一个记录数据结构学习过程的 C++ 项目，主要用于整理课程作业、算法实现、测试案例与复杂度分析。

## 项目简介

本项目以数据结构课程的学习内容为主线，通过编写代码、调试程序和分析算法复杂度，加深对数据结构及其基本操作的理解。

项目不仅记录最终实现，也会整理设计思路、测试结果和学习过程中遇到的问题，方便后续复习与持续改进。

## 项目结构

## 学习内容

### 01 线性表（Linear Lists）

当前主要学习和实践链表的基本操作，包括：

- 单链表的建立与基本操作
- 双向循环链表与头结点
- 链表的合并与拆分
- C++ 模板类与指针操作
- 算法的时间复杂度与空间复杂度分析

后续将继续整理顺序表及其他线性表相关内容。

## 学习与整理方式

对于每道具有代表性的练习，尽可能记录以下内容：

1. **问题与设计思路**：理解题目要求，说明所采用的数据结构与算法。
2. **代码实现**：使用 C++ 完成实现，并逐步改善代码结构。
3. **测试案例**：覆盖常规情况与边界情况，检查程序的正确性。
4. **复杂度分析**：分析算法的时间复杂度与空间复杂度。
5. **问题总结**：记录调试过程中遇到的问题、解决方法及后续改进方向。
