## 练习内容

### 01. 链表拆分（Split）

**主要内容：**
- 使用 C++ 模板类实现双向循环链表
- 理解头结点及其初始化方式
- 实现链表节点的插入与指针连接
- 遍历原链表，根据节点索引的奇偶性将元素分配到两个新链表
- 分析算法的时间复杂度与空间复杂度

**实现思路：**

从原链表的第一个数据节点开始遍历，以头结点作为循环链表的遍历终止标志。根据当前节点的索引，将元素插入对应的链表。

当前实现采用新建节点、复制元素的方式，保留原链表不变。

**涉及的知识点：**
- 单链表与双向循环链表
- 头结点与哨兵节点
- 指针的连接与修改顺序
- C++ 模板类
- 链表遍历与插入
- 时间复杂度与空间复杂度
